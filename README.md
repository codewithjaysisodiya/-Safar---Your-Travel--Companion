# 🧳 Safar - Your Travel Companion - Discover Incredible India
> Your next beautiful journey starts here.

Safar - Your Travel Companion is a modern, responsive travel platform that helps users discover India's most beautiful destinations. From Taj Mahal to Goa beaches, find hidden gems and plan your perfect escape.

**Live Demo:** https://codeswithjaysisodiya.github.io/safar-app/

### ✨ Features
- 📍 **State-wise Search:** Select any state (UP, Rajasthan, Kerala, Goa etc.) and discover places
- 🏔️ **Popular Destinations:** Curated cards - Taj Mahal, Manali, Jaipur, Kerala, Goa
- 🗺️ **Curated Experience:** Hidden gems beyond tourist spots
- 📊 **Stats Section:** 28+ States, 500+ Places showcase
- ❤️ **Why Safar Section:** Feature highlights with modern UI
- 📱 **Fully Responsive:** Navbar with hamburger menu, mobile-friendly
- 🎨 **Premium UI:** Playfair Display + Inter fonts, overlays & animations

### 🛠️ Tech Stack
- **Frontend:** HTML5, CSS3, Vanilla JavaScript
- **Styling:** Custom CSS (`css/style.css`), Google Fonts (Inter & Playfair Display)
- **Logic:** `js/script.js` for state filter & explore functionality
- **Icons:** Emoji-based icons (📍 ✈️ 🗺️)
